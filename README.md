- **Antigravity Agent Panel.** A live panel that shows what each AI agent spends in tokens, context and cost. Public and open source: [antigravity-agent-panel](https://github.com/mdnaeem-28/antigravity-agent-panel)
- **Booking UX portfolio demo.** A fictional designer's portfolio with components, tokens and a clickable prototype, built with AI under my direction: [live site](https://mdnaeem-28.github.io/arif-chowdhury-portfolio-demo/)
